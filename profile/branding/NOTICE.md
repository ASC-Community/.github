# Angouri wordmark

Generated from the shared website wordmark and canonical cucumber drawing by `scripts/export-brand.mjs` in [ASC-Community/Angouri](https://github.com/ASC-Community/Angouri). The dark-background variant changes only the lettering and dot color. The SVGs contain paths, with no embedded font or external resources.

Letter outlines are derived from KaTeX_Main-Italic distributed with [KaTeX](https://github.com/KaTeX/KaTeX). The font's notice is:

http://scripts.sil.org/OFL

To regenerate, build and serve the Angouri website, then run `npm run export:brand`. Review the files in `artifacts/branding/` and copy them here.
