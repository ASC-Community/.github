## Projects

### AngouriMath ![GitHub Repo stars](https://img.shields.io/github/stars/asc-community/AngouriMath?style=social)

<img src="https://github.com/asc-community/AngouriMath/raw/master/.github/additional/readme/icon_white.png" width="120" align="left" alt="AngouriMath icon">

[**AngouriMath**](https://github.com/asc-community/AngouriMath) is a symbolic algebra library for working with math expressions and the only actively maintained and developed symbolic algebra library for .NET. It performs arithmetic, calculus, linear algebra, boolean logic and set operations, parses expressions, and builds their LaTeX representations. Computation interruption and its F# wrapper make it convenient for industrial use. It is suited for C# and F#.

[GitHub](https://github.com/asc-community/AngouriMath) · [Website](https://am.angouri.org/) · [E-Mail](mailto:am@angouri.org): am@angouri.org

### GenericTensor ![GitHub Repo stars](https://img.shields.io/github/stars/asc-community/GenericTensor?style=social)

<img src="https://github.com/asc-community/GenericTensor/raw/master/ico1.png" width="120" align="left" alt="GenericTensor icon">

[**GenericTensor**](https://github.com/asc-community/GenericTensor) is the only fully implemented generic tensor library for C#. It works with generic multidimensional arrays, supports some matrix operations, and allows tensors of custom types. Operations rely on a special provider for the element type; for example, adding two arrays requires a method that adds two values of type `T`. It is also optimized as much as possible while still supporting any type.

[GitHub](https://github.com/asc-community/GenericTensor)

### Honk# ![GitHub Repo stars](https://img.shields.io/github/stars/ASC-Community/HonkSharp?style=social)

<img src="https://github.com/ASC-Community/HonkSharp/raw/main/HonkSharp/logo256.png" width="120" align="left" alt="Honk# icon">

[**Honk#**](https://github.com/ASC-Community/HonkSharp) is a general-purpose library aimed at making declarative programming in C# easier. It provides fluent method extensions such as `Pipe`, lazy properties, and an anonymous union type. It may fit projects that cannot afford to be rewritten in more declarative languages but would benefit from such features.

[GitHub](https://github.com/ASC-Community/HonkSharp)

### MxEngine

[**MxEngine**](https://github.com/asc-community/MxEngine) is an educational modern C++ general-purpose 3D game engine. Right now MxEngine is developed only by [#Momo](https://github.com/MomoDeve), but any contributions are welcome and will be reviewed. For now MxEngine supports OpenGL as its graphics API and targets x64 only.

[GitHub](https://github.com/asc-community/MxEngine)

### MonoBind

<img src="https://github.com/ASC-Community/monobind/raw/master/monobind-logo.png" width="180" align="left" alt="MonoBind wordmark">

[**MonoBind**](https://github.com/asc-community/monobind) is a lightweight header-only library that exposes C++ types in C# and vice versa, mainly to create C# bindings of existing C++ code.

[GitHub](https://github.com/asc-community/monobind)
